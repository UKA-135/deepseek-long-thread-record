# UKA-135: Long-Term Human Engagement with AI (550,000+ Word Single-Thread Dataset)

**UKA-135** (`deepseek-long-thread-record`) is an audited, pseudonymized dataset documenting extreme **long-term human-AI interaction** within a single continuous session. Recorded over six days with DeepSeek, the transcript spans **500,000+ words**, **742 conversational turns**, and **135 distinct knowledge domains**.
